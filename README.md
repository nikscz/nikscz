# Tools by nikscz

Claude Code plugins by nikscz. Every tool is its own repo. Each plugin has its own install instructions in its README.

- nix-done-sound: Pick your own alert sound for when Claude is done. https://github.com/nikscz/nix-done-sound
- nix-checklist-sidebar: Claude's work plan as a plain-language checklist in a narrow sidebar. https://github.com/nikscz/nix-checklist-sidebar
- nix-progress-bar: Progress bar with a learning time estimate above the message box. https://github.com/nikscz/nix-progress-bar
- nix-note: /note saves project notes that Claude knows and applies. https://github.com/nikscz/nix-note
